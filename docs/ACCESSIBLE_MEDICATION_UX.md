# Доступный UX для напоминаний о лекарствах

Этот документ — обязательная продуктовая спецификация для экранов лекарств, расписания и уведомлений. Целевая аудитория включает пожилых пользователей, людей со сниженным зрением/слухом/моторикой и пользователей, которые не обязаны разбираться в настройках Android.

## Базовый принцип

Пользователь никогда не должен гадать:
- что заполнить;
- что обязательно;
- почему действие не сработало;
- сохранились ли данные;
- придёт ли уведомление;
- что нажать дальше.

Никаких молчаливых отказов. Ошибка всегда содержит человеческое объяснение и конкретное следующее действие.

## Добавление лекарства

Минимум обязательных данных: название и расписание для препаратов с автоматическими напоминаниями. Дозировка имеет понятное значение по умолчанию (например, `1 таблетка`) и может быть изменена. Все дополнительные параметры необязательны и не блокируют сохранение, если пользователь их не включал.

Дополнительные параметры раскрываются постепенно: курс, остаток, расход за приём, напоминание о покупке, еда, заметка, индивидуальный звук/голос и другие расширенные настройки.

Если поле не заполнено или заполнено неверно, экран прокручивается к нему и показывает конкретную подсказку, например: `Укажите время, например 08:30`. Нельзя просто отключать кнопку без объяснения причины.

## Дубликаты лекарств

Одинаковое название не запрещает создание второй записи. При совпадении показывать спокойный выбор:
- `Открыть существующее` — перейти к редактированию найденной записи;
- `Добавить ещё одно` — продолжить создание новой записи с тем же названием.

Не показывать блокирующее сообщение вида «уже есть, откройте его» без возможности продолжить.

## Название и клавиатура

При открытой клавиатуре активное поле остаётся видимым. Экран прокручивается, а нижние кнопки не накладываются на поле или подсказки. Автодополнение ограничено доступной высотой, прокручивается отдельно и не уходит под клавиатуру. Всегда остаётся возможность ввести произвольное название вручную.

Проверять минимум на маленьком Android-экране, при обычном и увеличенном системном шрифте.

## Время

Ввод времени должен быть быстрым:
- готовые варианты `Утро`, `День`, `Вечер`, `На ночь` с видимым точным временем;
- несколько времён для одного лекарства;
- `+ Добавить время`;
- изменение конкретного времени нажатием на него;
- ручной ввод цифр с нормализацией, например `830` -> `08:30`;
- конкретные дни недели, ежедневно, через N дней, по необходимости и другие режимы по мере реализации.

Не заставлять пользователя проходить отдельный сложный picker для каждого времени, если можно выбрать готовый вариант.

## Уведомления и звук

Для каждого лекарства поддерживается отдельный способ оповещения, с общими настройками по умолчанию:
- мелодия;
- системный русский голос;
- собственная запись;
- без голоса / только сигнал и вибрация.

Обязательны три независимые проверки:
1. `Послушать мелодию` — играет только выбранная мелодия.
2. `Послушать голос` — звучит только TTS или собственная запись, без мелодии.
3. `Проверить всё напоминание` — сначала мелодия, затем выбранный голос/запись.

Кнопка прослушивания голоса никогда не должна запускать мелодию.

Системный TTS произносит данные конкретного лекарства, например: `Время принять Нексиум. Одна таблетка.` Если дозировка не указана, произносится только название.

Для собственной записи: `Записать` -> `Стоп` -> `Прослушать` -> `Использовать`. Не требовать выбора аудиофайлов вручную.

## Проверка работоспособности

В настройках должен быть мастер диагностики:
- уведомления разрешены / не разрешены;
- точные будильники разрешены / не разрешены;
- звук доступен;
- голос доступен;
- тестовое напоминание.

После теста спрашивать `Вы услышали напоминание? Да / Нет`. При `Нет` помогать проверить канал уведомлений, системную громкость, DND, точные будильники и ограничения батареи. После возврата из системных настроек автоматически перепроверять состояние.

## Остаток лекарства

Опционально: `Следить за остатком`. По умолчанию выключено. При включении:
- текущий остаток;
- расход за один приём;
- порог или количество дней до предупреждения;
- автоматическое уменьшение после подтверждённого приёма;
- простое добавление новой упаковки.

Отсутствие этих данных не мешает пользоваться обычными напоминаниями.

## Доступность

- Основные touch targets ориентировочно от 48 dp.
- Не полагаться только на цвет или иконку: состояние сопровождается текстом.
- Поддерживать увеличенный системный шрифт без наложений и обрезки.
- Крупные кнопки для основных действий: `Принято`, `Отложить`, `Пропустить`.
- Последовательная навигация и одинаковые названия одинаковых действий.
- Не требовать drag-жестов для обязательных операций.
- Не заставлять повторно вводить уже известные данные.

## Обратная связь

После действий явно показывать результат: `Лекарство сохранено`, `Напоминание установлено на 08:00`, `Отложено до 08:15` и т. п.

Если лекарство сохранилось, но уведомление поставить не удалось, сообщать обе части: `Лекарство сохранено, но напоминание сейчас не сработает` и давать кнопку для исправления разрешения.
