# Конфигурация агентов

Инструкции для всех ИИ агентов, работающих с проектом Pills-05.

## 🤖 Агент: safe-agent

Это основной режим разработки для этого проекта.

### ✅ ЧТО РАЗРЕШЕНО

#### Разработка
- Писать новый код в соответствии со спецификацией
- Исправлять баги в существующем коде
- Оптимизировать производительность
- Добавлять TypeScript типы
- Улучшать обработку ошибок

#### Структура
- Создавать новые файлы в соответствии со структурой
- Разделять логику по модулям
- Организовывать imports
- Добавлять новые routes/features

#### Тестирование
- Запускать разработческий сервер
- Тестировать напоминания вручную
- Проверять UI в браузере
- Смотреть логи в консоли

### 🚫 ОГРАНИЧЕНИЯ (CONSTRAINTS)

Следующие изменения **ЗАПРЕЩЕНЫ БЕЗ ЯВНОГО РАЗРЕШЕНИЯ:**

- ❌ Менять структуру папок в `src/`
- ❌ Объединять файлы из разных features
- ❌ Менять UX потоки основной логики
- ❌ Менять тексты интерфейса (кроме ошибок)
- ❌ Переименовывать основные экраны
- ❌ Удалять напоминания или их функциональность

### 🚫 ЗАПРЕТЫ (PROHIBITIONS)

**АБСОЛЮТНО ЗАПРЕЩЕНО:**

- ❌ Писать весь код в одном файле
- ❌ Создавать файлы больше 300 строк (максимум 400)
- ❌ Ломать функциональность напоминаний
- ❌ Удалять проверки и валидацию
- ❌ Игнорировать TypeScript ошибки
- ❌ Создавать orphan данные в localStorage
- ❌ Менять формат хранения данных без миграции
- ❌ Удалять обработчики ошибок

## ✔ ПРОВЕРКИ (VERIFICATION)

### До каждого коммита

- ✅ Все кнопки на экране дают видимый ответ
- ✅ Нет молчания интерфейса (deadlock)
- ✅ Нет дубликатов в хранилище данных
- ✅ Старые уведомления удаляются
- ✅ TypeScript компилируется без ошибок
- ✅ Нет console.error в нормальном потоке

### Функциональные проверки

#### Напоминания
- ✅ Экран показывается
- ✅ Звук воспроизводится
- ✅ Голос говорит "Время принимать таблетки"
- ✅ Push-уведомление приходит
- ✅ Повторения работают правильно (5, 10 мин)

#### Кнопки
- ✅ "Я принял" отмечает прием
- ✅ "Пропустил" показывает сообщение
- ✅ "Отложить" ставит напоминание на позже
- ✅ Все кнопки меняют цвет

#### Данные
- ✅ Добавление лекарства сохраняется
- ✅ Удаление лекарства полное
- ✅ История приёма актуальна
- ✅ Нет orphan записей

## 🔄 Процесс работы

### 1. Планирование
- Прочитать требования в CLAUDE.md
- Понять архитектуру (ARCHITECTURE.md)
- Спланировать изменения

### 2. Разработка
- Писать код в соответствии со структурой
- Соблюдать размер файлов (≤300 строк)
- Проверять типы TypeScript

### 3. Тестирование
- Запустить dev сервер
- Протестировать UI вручную
- Проверить напоминания
- Смотреть консоль на ошибки

### 4. Коммит
- Проверить все пункты выше
- Написать понятное сообщение коммита
- Запушить на ветку разработки

### 5. Обзор
- Убедиться, что все требования выполнены
- Нет регрессий в функциональности

## 🛠 Инструменты

### Основной стек
- **Framework:** Next.js 14 (App Router)
- **Язык:** TypeScript
- **Стили:** Tailwind CSS
- **State:** Zustand
- **Данные:** localStorage
- **Сборка:** next build

### Разработка
```bash
npm run dev          # Стартует на http://localhost:3000
npm run build        # Собирает для production
npm run type-check   # Проверка TypeScript
```
