# Напоминание о лекарствах

Простое приложение для пожилых людей, которое помогает не забыть принять лекарство.

## Главная задача

Напомнить принять лекарство и дать нажать кнопку подтверждения.

## Как пользоваться

1. **Добавить лекарство** — введите название и расписание
2. **Выбрать режим** — ежедневно, через день, по необходимости
3. **Выбрать время** — утро, день, вечер или своё время
4. **При напоминании нажать кнопку** — "Я принял"

## Установка

- Откройте сайт в браузере
- Нажмите кнопку "Установить приложение"
- Позже будет доступен APK для Android

## Важные принципы

- **Максимально простое** — без сложных настроек
- **Работает без интернета** — все данные в памяти телефона
- **Громко напоминает** — экран, звук, голос, push-уведомление
- **Надёжное** — нет ошибок, кнопки всегда реагируют

## Напоминания

Когда пришло время принимать лекарство:

- На экране появляется большое напоминание
- Звучит звук или голос: "Время принимать таблетки"
- Появляется push-уведомление
- Если забыли — повтор через 5 минут, затем через 10 (максимум 3 раза)

## История приёма

- Можно посмотреть, когда в последний раз принимали лекарство
- История сохраняется в приложении

## Требования к браузеру

- Modern браузер с поддержкой PWA
- localStorage
- Web Audio API
- Speech Synthesis API
